历史变化：
初代还是笔记软件里的一篇纯文本笔记，它将散落的浏览器书签聚集在一个页面；
第一代是以简书为代表的博客类平台，但是目前发现更新外部链接的时候，会遇到审核或禁止发布的问题；
第二代是以语雀为代表的云端笔记软件，它们提供了分享功能，可以将笔记页面发布到一个网址上，但是也同样存在各种问题；
第三代是以 Github Pages 为代表的云端部署平台，相似的还有 Cloudflare Pages 我打不开， Vercel 与 Netlify 我不会用，而且 Github Pages 还可以被搜索引擎收录呢，所以是一个不错的选择。
